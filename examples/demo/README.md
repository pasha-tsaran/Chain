# Учебный пример

Этот пример опубликован для проверки задания без установки локальных моделей.

- [article.md](article.md) — статья в Markdown с двумя иллюстрациями.
- [article.html](article.html) — тот же результат в HTML; для просмотра скачайте пример вместе с папкой `images` и откройте файл в браузере.
- [plan.json](plan.json) — результат первого этапа цепочки: ракурс, план и описания сцен.
- [report.json](report.json) — модели, версии, настоящие оценки ZeroGPT и контрольные суммы.
- [revisions.json](revisions.json) — десять точечных замен: исходные и новые фрагменты.
- [images/](images/) — две картинки, созданные локальной SD-Turbo.

Первый результат детектора — **32,6%** для версии 2; после одного прохода точечных правок — **0%** для версии 3. Неизменность остального текста проверена программно.

Статья остаётся примером результата небольшой локальной модели, а не образцом литературного качества. Оценка детектора не заменяет редактуру и проверку фактов. Скриншоты находятся в [docs/screenshots](../../docs/screenshots/).
