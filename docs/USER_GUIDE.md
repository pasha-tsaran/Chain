# Подробная инструкция: «Редакция»

Локальное приложение для Windows. Тема → план → текст → литературная редактура → 1–2 картинки → проверка на ИИ → точечная доработка. Статьи, изображения и версии сохраняются на компьютере.

## Запуск

1. Первый раз откройте **Установить модели.cmd**. Нужны Python 3.12, установленная Ollama, интернет и свободное место на диске. Установка загружает Qwen3 8B, библиотеки PyTorch и модель SD-Turbo; загрузка может занять значительное время. Уже установленные компоненты используются повторно.
2. Откройте **Запустить Редакцию.cmd**. Приложение откроется по адресу [http://127.0.0.1:8765](http://127.0.0.1:8765).
3. Введите тему, аудиторию и пожелания. Для проверяемых фактов вставьте материалы с адресами источников. Выберите объём, подачу и число иллюстраций. Нажмите **Создать статью**.
4. Для автоматического бесплатного режима выберите в настройках **Автоматически через бесплатный сайт ZeroGPT (Edge)**. Приложение передаст текст в форму сайта, получит процент и подсветку. Нужны интернет и установленный Microsoft Edge. Этот режим включён в подготовленном приложении на данном компьютере; в чистой установке сначала выбран ручной режим.
5. При результате **выше 10%** редактор заменит только указанные цитаты и повторит проверку. При результате **10% и ниже** приложение отметит достижение порога. По умолчанию разрешены три доработки. Если сайт потребует CAPTCHA, ограничит проверки или изменит интерфейс, приложение предложит ручной перенос отчёта: скопируйте текст, откройте ZeroGPT, верните процент и точные цитаты, разделённые пустой строкой.
6. Скачайте ZIP. Внутри `article.html`, `article.md`, `detector-text.txt`, папка `images` и `report.json`. Откройте HTML, проверьте статью и перенесите её в редактор Дзена; картинки загрузите отдельно. Отображение таблиц проверьте в самом Дзене.

Приложение работает в фоне после закрытия вкладки. Повторный запуск открывает тот же сервер. Для ручного запуска: `.venv\Scripts\python.exe server.py`. Остановка фонового процесса Python прекращает сервер; на следующем старте незавершённая задача отмечается как прерванная, черновики сохраняются. Автозапуск Windows не устанавливается.

## Бесплатный детектор и автоматизация

Выбран [ZeroGPT](https://www.zerogpt.com/). На момент проверки сайт предоставляет бесплатную форму с лимитом 15 000 символов и подсветкой предложений. Условия и доступность могут меняться; русский язык заявлен как часть многоязычной поддержки, но независимая точность на русском здесь не измерялась.

**Бесплатная автоматизация работает через публичную форму сайта.** Локальный Playwright открывает отдельный фоновый Edge без ваших личных cookies, заполняет форму и читает видимый отчёт. Скрытый API не используется. Изменение сайта, CAPTCHA, сетевые ограничения или исчерпание бесплатного лимита могут остановить этот режим. Тогда доступен ручной перенос, без выдуманного процента.

Официальный [ZeroGPT Business API](https://api.zerogpt.com/docs) является платным и подключается отдельно через JWT и API Key. Он также поддерживает автоматическую проверку, точечную доработку и повторный запрос. Интеграция API покрыта тестами на контролируемых ответах; реальные платные запросы без ваших ключей не выполняются. Бесплатный браузерный режим проверен на настоящей статье: 32,6% → 0% после одного прохода точечных правок. Это результат конкретного испытания, не обещание для любых тем.

Ключи хранятся в `data/settings.json`, который не входит в исходный архив. Альтернатива — переменные окружения `ZEROGPT_TOKEN` и `ZEROGPT_API_KEY`; перезапустите сервер после их задания. Выбор автоматического режима в настройках разрешает передачу статьи в ZeroGPT; напоминание об этом видно рядом с созданием статьи. В ручном режиме вы отправляете текст сами. Приложение не обходит CAPTCHA и ограничения сервиса.

Если процент больше 10%, а подсветки нет, приложение запросит цитаты. Ошибка сервиса не засчитывается как 0%. Неполные, неоднозначные и пересекающиеся цитаты отклоняются. После изменения текста отчёт предыдущей версии теряет силу. Если порог не достигнут за отведённое число доработок, статья остаётся для ручной редакции.

## Можно ли полностью локально?

**Текст и картинки — да.** Используются Ollama + Qwen3 8B и отдельный процесс SD-Turbo. После первоначального скачивания они могут работать без интернета. Компьютер, на котором готовилось приложение: RTX 3070 Laptop с 8 ГБ видеопамяти. Модели работают последовательно: Ollama освобождает видеопамять перед картинками, а процесс изображений затем завершается. Скорость зависит от оборудования, объёма и контекста. Наличие 8 ГБ само по себе не гарантирует отсутствие нехватки памяти, если GPU занят другими приложениями.

**Онлайн-проверку ZeroGPT локальная языковая модель не заменяет.** Можно подключить отдельную локальную модель классификации, но её результат не будет процентом ZeroGPT. Приложение не выдаёт литературное ревью или простую эвристику за измеренный процент ИИ. Локальный детектор в этой версии не включён.

**Гарантировать ≤10% нельзя.** Разные детекторы расходятся, ошибочно помечают человеческий текст и пропускают машинный. Порог — ваш рабочий критерий для конкретного сервиса, а не доказательство человеческого авторства. Качество текста и достоверность фактов следует оценивать отдельно.

## Ограничения и качество

- Формат подачи в режиме «Разная в каждой статье» меняется между соседними статьями. Это не гарантия уникальности каждой формулировки; семантический антиплагиат не включён.
- Автор не получает автоматический поиск в интернете. Ссылки из материалов не открываются автоматически. Вставляйте нужные факты и выдержки; важные утверждения проверьте перед публикацией.
- Литературное ревью выполняет модель: она может пропустить ошибку. Приложение проверяет объём и защищает границы замен, но не сертифицирует истинность статьи.
- Локальные модели на 7–8 млрд параметров в испытаниях допускали опечатки, речевые повторы и неудачные советы. Второй проход редактора уменьшает часть ошибок, но перед публикацией текст нужно прочитать. В настройках можно выбрать другую установленную модель Ollama.
- SD-Turbo — компактная быстрая модель. Возможны артефакты, ошибки анатомии и слабая передача сложных сцен. Для более качественных картинок можно подключить локальный WebUI/Forge с API и своей моделью. [Описание SD-Turbo и условия использования](https://huggingface.co/stabilityai/sd-turbo) следует учитывать при коммерческой публикации.
- Картинки создаются по плану статьи и сохраняют описания сцен и seed. Перед публикацией проверьте, что иллюстрации соответствуют финальному тексту. После ручного изменения темы пересоздайте картинки.
- Доступ к приложению открыт только с этого компьютера (`127.0.0.1`). Данные лежат в `data/`, веса изображений — в `models/`, веса текста хранятся в Ollama. ZIP с исходным кодом не включает данные, секреты и веса.
- Публикация в Дзен выполняется вами. Авторизация в Дзене не требуется.

## Если что-то не работает

**Модель не найдена:** запустите Ollama и установку моделей. Список установленных моделей доступен в настройках. Уже установленную Llama 3.2 3B можно выбрать для эксперимента, но качество русского текста может быть ниже.

**Нет картинок:** статья сохранена. Проверьте `data/articles/<id>/images.log`, завершите установку и нажмите «Создать картинки заново». Полный журнал сервера — `server.log` (при проверке разработки также `server-error.log`).

**Ошибка загрузки PyTorch:** повторите установку. Для Windows + Python 3.12 предусмотрен резервный загрузчик `python download_torch.py`: он скачивает официальный wheel частями и проверяет SHA256 по официальному индексу. После загрузки установите файл из `data/wheels` в `.venv`, затем повторите установку моделей.

**Нужен другой порт:** запустите `.venv\Scripts\python.exe server.py --port 8766` и откройте соответствующий адрес. Стандартный ярлык использует 8765.

## Проверка кода и устройство цепочки

`python -m unittest discover -s tests -v` — тесты точечных замен, неизменности соседнего текста, устаревших отчётов, порога, повторной проверки, лимита доработок, экспорта и HTTP-защиты.

- `workflow.py`: четыре этапа, версии, точечное редактирование, повторная проверка.
- `prompts.py`: отдельные промпты анализа, автора, редактора и замены цитаты.
- `providers.py`: Ollama и официальный ZeroGPT Business API.
- `browser_detector.py`: бесплатная автоматическая проверка через видимую форму ZeroGPT в изолированном Edge.
- `image_worker.py`: локальная генерация PNG в отдельном процессе.
- `server.py`, `static/`: локальный сервер и интерфейс без CDN.
- `storage.py`: SQLite и настройки.
- [Промпт разработки и его анализ](../ПРОМПТ_И_АНАЛИЗ.md): связь с уроком, требования и границы гарантий.

Веб-сервер и оркестрация используют стандартную библиотеку Python. Для изображений нужны зависимости из `requirements-images.txt`. Доступ к модели через HTTP организован явной цепочкой; LangChain не требуется.
